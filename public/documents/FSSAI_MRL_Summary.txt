CRITICAL COMPLIANCE POINTS FOR FARM MANAGEMENT
================================================================================

1. WITHDRAWAL PERIOD MANAGEMENT:
   ⚠️  FSSAI document does NOT specify withdrawal periods explicitly
   ⚠️  Refer to veterinary medicine package inserts
   ⚠️  Generally:
       - Systemic antibiotics: 3-7 days
       - Macrolides: 5-10 days
       - Aminoglycosides: 10-14 days
       - Beta-lactams: 2-5 days

2. TESTING REQUIREMENTS:
   ✓ Establish baseline testing for all animal products
   ✓ Fish/Seafood: Test for tetracyclines, fluoroquinolones
   ✓ Poultry/Eggs: Test for macrolides, aminoglycosides
   ✓ Dairy: Test for beta-lactams, macrolides
   ✓ Honey: LC-MS/MS analysis required for accurate detection

3. TISSUE-SPECIFIC TESTING:
   ✓ Kidney: Often has highest MRL (10x muscle in some cases)
   ✓ Liver: Usually 2-5x higher than muscle
   ✓ Milk: Often lowest MRL (most stringent)
   ✓ Eggs: Moderate MRL, chicken-specific

4. ZERO-TOLERANCE SUBSTANCES:
   ⛔ Nitrofurans - complete prohibition
   ⛔ Chloramphenicol - nearly complete (except 0.3 μg/kg in honey)
   ⛔ Crystal Violet, Malachite Green - dye contaminants

5. METAL CONTAMINATION HOTSPOTS:
   🔴 Seafood: Often highest Cd, Hg limits
   🔴 Rice: Cadmium accumulation (0.4 mg/kg)
   🔴 Spices: Lead accumulation (10.0 mg/kg)
   🔴 Molluscs: High Cd/Pb due to filter-feeding

NOTES FOR PORTAL DEVELOPERS
================================================================================

1. DATA CURRENCY:
   - Last update from FSSAI: January 28, 2022
   - Check FSSAI website quarterly for amendments
   - Create update notification system

2. TESTING METHODOLOGY:
   - Honey analysis requires LC-MS/MS
   - Standard HPLC acceptable for most products
   - Atomic absorption for heavy metals

3. LIMIT INTERPRETATIONS:
   - LOQ (Limit of Quantification) = measurable threshold
   - Some limits use "F" notation (fat basis calculation)
   - Tissue-specific limits apply to that tissue type only

4. REGULATORY COMPLIANCE:
   - Any product exceeding MRL is non-compliant
   - EMRL (Extraneous MRL) for prohibited substances = zero tolerance
   - Documentation required for all testing

5. AUDIT TRAIL:
   - Maintain records for 2 years minimum
   - Track all treatment dates and dosages
   - Link to withdrawal period compliance
   - Keep test certificates
